# PixAI 태그 서랍 (크롬 확장)

PixAI 프롬프트 태그를 **한글로 찾고, 저장하고, 클릭 한 번으로 넣는** 사이드 패널이에요.

## 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
4. 툴바의 퍼즐 아이콘에서 핀 고정 → 아이콘을 누르면 사이드 패널이 열려요
5. 이미 열려 있던 PixAI 탭은 **새로고침** 한 번 해 주세요

## 탬퍼몽키 버전 (자동 업데이트)
크롬 확장 대신 탬퍼몽키로도 쓸 수 있어요. 크롬·엣지·웨일·파이어폭스 모두 되고, **새 버전이 올라오면 탬퍼몽키가 알아서 업데이트**해요.

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치
2. 아래 링크를 열면 탬퍼몽키 설치 화면이 떠요 → **설치**
   https://raw.githubusercontent.com/kkm4244-gif/claude/claude/pixai-tag-storage-db779j/userscript/pixai-tag-drawer.user.js
3. PixAI를 새로고침하면 오른쪽에 패널이 떠요. 오른쪽 가장자리의 **🏷 태그 서랍** 버튼으로 열고 닫아요.

- 크롬 확장과 탬퍼몽키는 저장 공간이 따로예요. 옮길 때는 **내 태그·백업 → 내보내기/가져오기**를 쓰세요.
- 둘을 동시에 켜 두면 기능이 겹치니 하나만 쓰는 걸 추천해요.
- 개발: `extension/`을 고친 뒤 `node tools/build-userscript.mjs`로 `userscript/`를 다시 만들어요.

## 사용법
- **검색**: `소매` → 소매 걷어올림 / 긴 소매 / 짧은 소매 …, `검은 머리`(두 단어 모두 포함), `ㅅㅁ`(초성), `sleeve`(영어)
- **넣기**: 태그를 클릭하면 PixAI에서 마지막으로 클릭한 입력칸의 커서 위치에 들어가요.
  쉼표는 자동으로 붙어요. 네거티브 칸을 먼저 클릭해 두면 네거티브에 들어가요.
  입력칸을 못 찾으면 클립보드에 복사돼요.
- **가중치**
  - 태그 목록에서 태그 위에 마우스를 올리고 `Shift + 휠` (태블릿은 **길게 누르기** → `−` `+` 바) → `(jitome:1.1)`, `(jitome:1.2)` … 그 상태로 클릭하면 가중치째 들어가요.
  - PixAI 입력칸에서 태그에 커서를 두거나 드래그로 선택하고 `Ctrl + ↑ / ↓`. 1.0이 되면 괄호가 사라져요.
  - 1.5를 넘으면 빨간색으로 표시돼요 (그림이 깨지기 쉬움).
- **프롬프트 탭**: 지금 PixAI 입력칸의 태그를 칩으로 보여줘요.
  - 칩 위에서 `Shift + 휠`(또는 길게 누르기)로 가중치를 바꾸면 PixAI 입력칸에 바로 반영돼요. `✕`로 삭제.
  - 칩 왼쪽 색은 정렬 그룹이에요.
  - **정렬 미리보기 → 적용**: `화질·화풍 → 인원 → 외형(머리·눈·체형) → 의상·소품 → 표정·포즈 → 구도 → 배경·조명` 순서로 정렬해요.
    중복 태그는 지우고, 오타 의심(`black shirts → black shirt?`)과 분류 못한 태그를 알려줘요.
    가중치 `(tag:1.2)`, `<lora:…>` 표기, `BREAK`는 그대로 유지돼요. PixAI 입력칸의 **LoRA 칩은 읽지도 건드리지도 않아요.** 적용 후 PixAI 입력칸에서 `Ctrl + Z`로 되돌릴 수 있어요.
- **충돌 경고** (프롬프트 탭): `smile ↔ bored`, `upper body ↔ full body`, 머리색·눈색 여러 개, `closed eyes ↔ looking at viewer`, `day ↔ night` 같은 어색한 조합을 알려주고 해당 칩에 빨간 테두리를 쳐요.
  대안도 같이 알려줘요 (예: 심드렁한 미소 → `light smile + half-closed eyes`). 한쪽 가중치가 0.8 미만이면 노란색(약한 경고)이에요.
  일부러 섞은 조합이면 **무시**를 누르면 그 조합은 다시 경고하지 않아요. 여러 명이 나오는 그림이면 머리색·눈색 같은 외형 경고는 건너뛰어요.
- **☆ 즐겨찾기**: 잘 먹히는 태그를 표시하면 검색 결과 위쪽에 떠요. 자주 쓴 태그도 위로 올라가요.
- **프리셋 (표정 레시피)**: 감정별 표정 조합 40개 (웃음, 도발·오만, 분노, 슬픔, 당황·부끄러움, 놀람, 냉담, 피곤·나른, 진지·긴장, 광기, 설렘·애정)와 배경 레시피 16개(저택 거실·서재·창가·바·호텔 등), 자연 레시피 17개(숲·바다·호수·폭포·벚꽃·설원·밤하늘 등), 섹시·분위기 레시피 10개(풀어헤친 셔츠·젖은 셔츠·샤워 후·요염한 눈빛 등), 색감 레시피 12개(톤다운·비비드·청량·네거티브용)가 기본으로 들어 있어요.
  기본 태그에 자연어 묘사와 시선·각도를 섞은 조합이라, 자연어를 잘 알아듣는 모델(예: Tsubaki.3)에서 감정이 더 살아나요.
  클릭하면 넣어지고, `✎`로 불러와 고친 뒤 **내 프리셋**으로 저장할 수 있어요. 캐릭터 설정이나 네거티브 세트도 같은 방식으로 저장하면 돼요.
  "PixAI 입력칸에서 가져오기"로 지금 쓰고 있는 프롬프트를 바로 프리셋으로 만들 수 있어요.
- **내 태그·백업**: 사전에 없는 태그를 한글 설명과 함께 추가하고, JSON으로 내보내기/가져오기 해요.
- **태그 한꺼번에 추가** (내 태그·백업 탭): `영어태그|한글설명|검색어`를 한 줄에 하나씩 붙여넣거나, `tag1, tag2, tag3`처럼 쉼표로 이어 붙여서 내 태그에 한 번에 넣어요. `#`으로 시작하는 줄은 건너뛰어요.

## 구성
| 파일 | 역할 |
|---|---|
| `extension/tags.js` | 기본 태그 사전 (1,184개, 남캐·성인 캐릭터 위주, `영어|한글|추가검색어` 한 줄씩) |
| `extension/presets.js` | 기본 표정 레시피 |
| `extension/sidepanel.*` | 사이드 패널 화면·검색·프리셋·백업 |
| `extension/prompt.js` | 프롬프트 파싱·가중치 계산 (패널과 페이지 공용) |
| `extension/sort.js` | 카테고리 순서 정렬, 중복·오타 검사 |
| `extension/conflicts.js` | 같이 쓰면 부딪히는 태그 규칙·검사 |
| `extension/content.js` | PixAI 페이지에서 입력칸 읽기/쓰기, `Ctrl+↑↓` 가중치 |

기본 사전은 대부분 Danbooru 표기를 따르고, PixAI 추천에서 확인한 표기(`sleeve rolled up`)는 그대로 넣었어요.
PixAI 추천과 다르게 보이는 태그는 **내 태그**로 같은 이름을 추가하면 덮어써져요.
