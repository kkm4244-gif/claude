# PixAI 태그 서랍 (크롬 확장)

PixAI 프롬프트 태그를 **한글로 찾고, 저장하고, 클릭 한 번으로 넣는** 사이드 패널이에요.

## 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
4. 툴바의 퍼즐 아이콘에서 핀 고정 → 아이콘을 누르면 사이드 패널이 열려요
5. 이미 열려 있던 PixAI 탭은 **새로고침** 한 번 해 주세요

## 사용법
- **검색**: `소매` → 소매 걷어올림 / 긴 소매 / 짧은 소매 …, `검은 머리`(두 단어 모두 포함), `ㅅㅁ`(초성), `sleeve`(영어)
- **넣기**: 태그를 클릭하면 PixAI에서 마지막으로 클릭한 입력칸의 커서 위치에 들어가요.
  쉼표는 자동으로 붙어요. 네거티브 칸을 먼저 클릭해 두면 네거티브에 들어가요.
  입력칸을 못 찾으면 클립보드에 복사돼요.
- **☆ 즐겨찾기**: 잘 먹히는 태그를 표시하면 검색 결과 위쪽에 떠요. 자주 쓴 태그도 위로 올라가요.
- **프리셋**: 자주 쓰는 조합(캐릭터 설정, 네거티브 세트 등)을 이름 붙여 저장하고 한 번에 넣어요.
  "PixAI 입력칸에서 가져오기"로 지금 쓰고 있는 프롬프트를 바로 프리셋으로 만들 수 있어요.
- **내 태그·백업**: 사전에 없는 태그를 한글 설명과 함께 추가하고, JSON으로 내보내기/가져오기 해요.

## 구성
| 파일 | 역할 |
|---|---|
| `extension/tags.js` | 기본 태그 사전 (약 390개, `영어|한글|추가검색어` 한 줄씩) |
| `extension/sidepanel.*` | 사이드 패널 화면·검색·프리셋·백업 |
| `extension/content.js` | PixAI 페이지에서 입력칸에 태그를 넣는 스크립트 |

기본 사전은 대부분 Danbooru 표기를 따르고, PixAI 추천에서 확인한 표기(`sleeve rolled up`)는 그대로 넣었어요.
PixAI 추천과 다르게 보이는 태그는 **내 태그**로 같은 이름을 추가하면 덮어써져요.
